# Stories do dia

Stories avulsos para postar no dia (não são destaques). A arte deixa a área de baixo livre para o adesivo do Instagram: coloque o adesivo nesse espaço.

## 22/11 · "Qual é a maior dor do seu negócio hoje?" (2 stories, nesta ordem)

Mostra as telas de verdade do que a Growlift monta (atendente de IA, Torpedo, painel do lucro e CRM), com dados de exemplo.

### 1 · Enquete
- **Arte:** `2026-11-22-1-enquete-maior-dor.png`
- **Como postar:** suba a imagem, toque em adesivos → **Enquete**, escreva a pergunta e as 4 opções, e coloque o adesivo no espaço de baixo, abaixo do "Vota aqui embaixo".

**Pergunta da enquete**
```
Qual é a sua maior dor hoje?
```

**Opções (uma em cada linha da enquete)**
```
Mensagem sem resposta
```
```
Cliente que some
```
```
Não sei o que dá lucro
```
```
Clientes desorganizados
```

### 2 · A resposta (com link)
- **Arte:** `2026-11-22-2-pra-cada-dor.png`
- **Como postar:** suba logo depois da enquete (ou umas horas depois, para quem votou ver a resposta). Toque em adesivos → **Link** e coloque o adesivo na luz azul, embaixo de "Toque no link e veja funcionando".

**Link do adesivo**
```
https://growlift.com.br/#funcoes
```

**Texto do adesivo**
```
Ver funcionando
```

**Se alguém votar e chamar no direct** (só responda quem falar com a gente; nada de mandar para quem só votou):
```
Oi! Aqui é da Growlift 👋 Vi que essa é a sua maior dor hoje. Quer que a gente te mostre como resolveria no seu negócio? É grátis: você conta sobre o negócio pelo site em 2 minutos e recebe um plano no WhatsApp: https://growlift.com.br/#diagnostico
Se não quiser receber mais mensagens nossas, responda SAIR.
```
